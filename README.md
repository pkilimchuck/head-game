# Головна гра

Сайт з психологічними тестами. Це один статичний файл `index.html`, збірка не потрібна.

## Як опублікувати на Vercel (безкоштовно)

1. Створи акаунт на github.com і новий репозиторій (наприклад, `head-game`).
2. Завантаж у нього всі файли з цієї папки (кнопка Add file, Upload files).
3. Зайди на vercel.com, увійди через GitHub, натисни Add New, Project, обери репозиторій і Deploy.
4. Через хвилину сайт буде за адресою `назва.vercel.app`.

## Свій домен пізніше

У Vercel відкрий Project, Settings, Domains, додай домен і скопіюй DNS-записи туди, де його купив.
